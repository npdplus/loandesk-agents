# v0.2.0 plan — Workflow and tools

**Goal:** a business can apply through the customer agent, a credit officer approves or rejects in an approval
step, and the agents call other systems: Dataverse, a mock Credit Score API and an MCP server.

Work through the steps in order. Each step ends with something you can check. Tick the box when it is done.

## Constraints

- **The maker's Copilot Studio trial ends around 3 December 2026** (decision D7). Steps that need Copilot
  Studio come first; the Azure-only steps (5, 6, 8) can run after it ends.
- **The trial cannot publish.** Channels and Entra ID sign-in (step 10) stay blocked until there is a licence
  that can publish. Everything else is tested in the Preview pane and the Evaluate tab.
- **Cost:** agent flow runs and evaluations use Copilot Credits (pay-as-you-go plan of `LoanDesk-Dev`);
  Azure Functions on a consumption plan and Application Insights stay inside their free grants at this
  volume. The USD 10 budget alert on `rg-loandesk-dev` still applies. Check the credits after each step.
- **Topics:** the current Copilot Studio experience de-emphasises topics, but the AB-620 study guide still
  lists topic skills (adaptive cards, variables, generative answers node). Step 2 finds where topics can
  still be built before steps 3 and 4 depend on it.
