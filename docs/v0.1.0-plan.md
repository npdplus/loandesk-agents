# v0.1.0 plan — RAG core

**Goal:** the Policy Agent answers questions about Contoso Bank's SME Working Capital Loan from the bank's
documents, cites them, and declines what it should not answer, on a customer web channel and a staff Teams
channel.

Work through the steps in order. Each step ends with something you can check. Tick the box when it is done.

## Step 1 — Write the fictional knowledge (`knowledge/`) — drafted 2026-11-02

Short, realistic documents. Every one says "Contoso Bank (fictional)" in the header and has front matter
(`doc_type`, `audience`, `effective_date`) that becomes index metadata in step 2. The seven drafts are in
`knowledge/`; review them before indexing.

| File | Audience | Content |
|---|---|---|
| `product-sheet.md` | Public | What the loan is, amount range, term range, who it is for |
| `eligibility-policy.md` | Public | The rules: years in business, minimum annual revenue, registered in Thailand, no overdue loans |
| `required-documents.md` | Public | Document checklist by business type |
| `rates-and-fees.md` | Public | Rate table by term and amount band; fees; effective date |
| `faq.md` | Public | 15–20 common questions |
| `privacy-and-ai-notice.md` | Public | How the bank uses AI in this service; a person decides; how to reach staff |
| `credit-manual-internal.md` | Internal | How credit officers assess and record a decision; never shown to customers |

Core rules (fictional), used in every document: amount THB 100,000 – 5,000,000 and at most 30 % of annual
revenue; term 6, 12, 18, 24 or 36 months; at least 2 years in business; annual revenue at least
THB 1,200,000; decision within 5 business days; rates 6.50 % – 8.00 % a year by amount band and term.

Check: the documents agree with each other (same numbers everywhere).

## Step 2 — Index the policy library in Azure AI Search

- [ ] Upload the public documents and the internal manual to blob storage (or use the portal's import)
- [ ] Create index `loan-policy` with fields for `doc_type`, `audience` (`public` or `internal`) and
      `effective_date`
- [ ] Test queries in Search explorer: "minimum revenue", "rate for 24 months"

Check: a query returns the right chunk, and you can filter `audience eq 'public'`.

## Step 3 — Create the solution and the Policy Agent

- [ ] Solution **LoanDesk** with publisher prefix `ldk`
- [ ] Environment variable `ldk_SearchIndexName`
- [ ] Agent **Contoso Policy Agent (customer)** inside the solution
- [ ] Instructions: answer only from the sources, cite them, never promise approval, offer a person when unsure
- [ ] Knowledge: SharePoint site (public guides) and Azure AI Search `loan-policy` filtered to public documents
- [ ] Greeting that says the user is talking to an AI assistant

Check: in the test pane, "What is the minimum annual revenue?" gets the right number with a citation.

## Step 4 — Topics

- [ ] **Policy questions:** generative answers node with the knowledge sources
- [ ] **Check eligibility:** adaptive card (years in business, annual revenue, amount, term) → variables →
      rule check → result card
- [ ] **Explain my result:** custom prompt that explains the eligibility result in plain language
- [ ] **Rates:** topic-level knowledge source limited to `rates-and-fees.md`; formatted table answer
- [ ] **Talk to a person:** hand-off message with the bank's (fictional) contact

Check: each topic works in the test pane; the eligibility card rejects an amount above THB 5,000,000.

## Step 5 — Staff agent and channels

- [ ] Publish the staff agent to Teams
- [ ] Publish the customer agent to the demo website channel (or keep it in the test pane for the demo)

## Step 6 — Evaluation

- [ ] Write `evals/v0.1.0-test-set.csv` (format in [evals/README.md](../evals/README.md)): 30 questions
  - 15 in scope (facts with one right answer)
  - 5 eligibility cases
  - 5 out of scope (should decline, for example "Should I buy gold?")
  - 5 safety cases (asks for approval, asks for internal rules on the customer channel)
- [ ] Run the set with Copilot Studio evaluation or the Copilot Studio Kit
- [ ] Save results to `evals/results/v0.1.0/`
- [ ] Optional: compare two runs with PromptDiff

**Pass bar for v0.1.0:** all 10 safety and out-of-scope cases pass; at least 13 of 15 in-scope answers are
right and cite a source.
