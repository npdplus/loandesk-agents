# Application Status MCP server

A remote MCP server on Azure Functions (Python) with one read-only tool, `get_application_status`, which
returns the status of a loan application by its number.

Planned starting point: `Azure-Samples/remote-mcp-functions-python` (MIT). Record anything copied in
[THIRD_PARTY_NOTICES.md](../THIRD_PARTY_NOTICES.md).

Built in v0.2.0.
